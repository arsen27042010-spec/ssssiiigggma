# Рубеж

Играбельный MVP браузерной стратегии по [исходному дизайн-документу](docs/country-game-design.md). Русский интерфейс, одна карта на 48 областей, до шести стран. Состоянием игры управляет сервер.

## Запуск

Нужен **Node.js 22 или новее**. Внешние зависимости, установка пакетов и сборка не требуются.

```powershell
cd C:\Users\ivanb\Documents\ChatGPT\War
node server/index.js
```

Откройте **http://localhost:3000**. В Windows также можно запустить `start.cmd` двойным щелчком. Остановка сервера в терминале — `Ctrl+C`.

Другой порт:

```powershell
$env:PORT = '3001'
node server/index.js
```

## Как начать

1. Введите название страны и создайте партию. Обычный матч длится 30 минут; режим ×4 проходит за 7,5 минуты реального времени.
2. В лобби выберите столицу из двух областей. Передайте код другим участникам и дождитесь их подключения.
3. Организатор нажимает «Начать матч». Одному тоже можно начать: это экономическая песочница без ботов.
4. Выберите свою область, настройте приоритет и постройте объект. Хозяйства уже производят базовую еду и материалы.
5. В «Армии» выберите разведотряд, нажмите «Переместить» и выберите видимую область на карте. Разведчики открывают две области вокруг себя.
6. Нейтральные земли на границе осваиваются за 60 денег и 30 материалов. Рудники требуют горной местности.
7. В «Торговле» создайте предложение. Другая страна покупает его: товар отправляется тремя партиями. До покупки видна оценка маршрута; у активной доставки можно задать промежуточную область кнопкой «Изменить маршрут».
8. Назначайте генералам зоны, задачи и бюджет. Передайте им отряды через панель армии. Ручной приказ возвращает контроль игроку.

Победа — по среднему ВВП за последние пять игровых минут либо полным захватом территорий всех соперников. Нейтральные земли для военной победы занимать не нужно. При равном результате победителей несколько.

## Несколько игроков

На одном компьютере удобно открыть **http://localhost:3000** и **http://127.0.0.1:3000**: у адресов отдельные хранилища сессий. Также подходят отдельные профили браузера или приватное окно. Обычные вкладки одного адреса управляют одной страной.

Для игры по локальной сети запустите сервер на компьютере организатора:

```powershell
$env:HOST = '0.0.0.0'
node server/index.js
```

Остальные открывают `http://<локальный-IP-организатора>:3000`, вводят название страны и код лобби. Все входят **до старта**. Публичный интернет-хостинг в эту поставку не входит; сервер рассчитан на локальный игровой тест.

## Что работает

- 48 областей, шесть стартов, три соседние области на страну, выбор столицы, лобби и таймер.
- Автоматический выпуск, рост населения, довольство, миграция, приоритеты и три режима налогов.
- Семь ключевых объектов; ограничения работников, энергии и сырья с объяснениями простоя.
- Производство металла, топлива, оружия, техники и боеприпасов. Таблица баланса едина для клиента и сервера: `public/catalog.js`.
- Торговые предложения, оценка доставки, резервирование товара/денег, три физических партии, обход наблюдаемой угрозы, ручная промежуточная точка, перехват и сопровождение. Во время боя сопровождения груз ждёт исхода; потерянная партия возвращает свою долю оплаты покупателю.
- Переводы и личные сообщения участникам матча.
- Пехота, танки, разведка и артиллерия; ручные приказы, автоматические бои, захват и восстановление.
- Снабжение по связанным территориям от столицы/склада, местный запас и штраф после его исчерпания.
- Три генерала: зоны, удержание/защита/наступление, зарезервированный бюджет, автоматическое пополнение и укрепление защищаемого объекта, возврат ручного контроля.
- Туман войны: история местности и наблюдаемых зданий, давность данных; скрытые отряды и чужие запасы не отправляются клиенту.
- Добавленная стоимость в ВВП, скользящее среднее и неизменяемые итоговые результаты.
- Восстановление страны после обновления страницы и перезапуска сервера. Повтор команды с тем же идентификатором не повторяет расходы.

## Осознанные упрощения

- Первая карта целиком связана сушей, море визуальное. Нет портов, морских перевозок и флота.
- Сухопутный торговый транзит открыт; дипломатические договоры пока заменены переговорами в чате. Перехват определяется активным приказом атаки, а не отдельным состоянием войны.
- Призыв сразу создаёт отряд при наличии людей и оборудования. Автоматическое пополнение генерала проверяется раз в 20 секунд; отдельной очереди обучения нет.
- Запасы ресурсов общие для страны. Модель физической перевозки работает для торговли; снабжение войск проверяет связность, а не отдельные грузовики.
- Генералы используют простые правила и сообщают текущую задачу; это не полноценные боты для одиночного режима. Нельзя автоматически заменить отключившегося участника.
- Нет парного режима, случайных карт, газет, событий, технологий, прогрессии и монетизации. Экономические оценки чужих стран до итогов не публикуются.
- Баланс требует партий с людьми: тесты проверяют правила, а не равную силу стратегий.

## Сохранение

Сервер атомарно записывает матчи и сессии в `data/matches.json` после команды и каждую реальную секунду. Секрет сессии хранится в браузере; не очищайте данные сайта, если хотите вернуться в текущую страну. Пока сервер работает, отключившаяся страна продолжает выданные приказы. Пока сам сервер выключен, игровое время стоит.

В один каталог данных должен писать один серверный процесс. Каталог `data/` исключён из Git. Перед переносом сохранения остановите сервер и скопируйте весь файл. Уже завершённый матч остаётся доступен для просмотра итогов.

## Проверка

```powershell
npm.cmd run check
```

Проверка синтаксиса и автотесты `node:test`. Тесты покрывают экономику, лимиты, разведку, повторные команды (включая специальные ключи объектов), HTTP-сессии и перезапуск, частичные доставки и возвраты, снабжение, полномочия генералов и победу. История ручной проверки — [docs/verification.md](docs/verification.md).

## Устройство проекта

| Каталог | Назначение |
| --- | --- |
| `game/` | Детерминированная симуляция, команды и фильтр наблюдений |
| `server/` | HTTP API, авторизация сессий и атомарное сохранение |
| `public/` | Интерфейс, SVG-карта и общий каталог баланса |
| `test/` | Автотесты правил и реального HTTP-сервера |
| `docs/` | Исходная концепция, решения MVP, план и протокол проверки |

HTTP API: `POST /api/matches`, `POST /api/join`, `GET /api/state`, `POST /api/command`. После входа запросы используют `Authorization: Bearer <token>`. Клиент получает только снимок своей страны и законно наблюдаемые сведения; частота опроса — одна секунда. Ядро не зависит от HTTP или SVG и может использоваться с другим рендерером.
